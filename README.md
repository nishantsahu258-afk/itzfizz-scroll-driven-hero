# Itzfizz Scroll Animation

A stunning, highly-responsive landing page featuring an intricate scroll-driven car animation. Built exactly to professional design specifications with a pixel-perfect layout and buttery-smooth micro-interactions.

## Features

- **Scroll-Driven Animation:** A McLaren drives horizontally across the screen mapped precisely to the user's scroll progress (both forward and reverse).
- **Staggered Reveals:** Letters and statistics smoothly fade in/out dynamically as the car approaches and passes them.
- **Pixel-Perfect Responsive Layout:** A "sandwich" core composition that perfectly maintains aspect ratios, scales gracefully down to mobile, and completely avoids vertical cutoff or horizontal bleeding.
- **Rich Visuals:** Custom blended CSS exhaust trail and dynamic drop shadows that interact with the dark road.
- **Modern Tech Stack:** Achieves 60fps animations entirely without heavy canvas or WebGL setups.

## Tech Stack

- **React.js** (Vite)
- **JavaScript**
- **Tailwind CSS** (for precise, responsive styling)
- **GSAP + ScrollTrigger** (for timeline-based scroll orchestration)

## How to run locally

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd scroll-animation
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
