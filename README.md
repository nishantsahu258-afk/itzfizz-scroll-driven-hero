## Overview
A high-performance, scroll-driven responsive hero section built as an internship assignment for Itzfizz. The project accurately matches the provided design reference and creates a fluid, cinematic experience across all viewports.

## Features
- Responsive hero section
- Staggered intro animations
- Scroll-driven car animation
- GSAP ScrollTrigger + scrub
- Letter reveal interaction
- Responsive desktop/tablet/mobile layout
- Performance-focused transforms

## Tech Stack
- React.js
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger
- Vite

## Run Locally
```bash
npm install
npm run dev
```
